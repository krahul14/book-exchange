# 📚 P2P Book Exchange App

A full-stack book exchange platform built with **Next.js 15**, **Tailwind CSS**, and **TypeScript**.

Users can register as **Book Seekers** or **Book Owners** to add, browse, and borrow books from each other.

## Installation Guide

cd book-exchange<br>

### Install dependencies
npm install

### run the dev server
npm run dev<br><br>

App runs at: http://localhost:3000
